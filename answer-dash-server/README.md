# 정답 질주 섬 — 무료 웹사이트 + 실시간 서버 (Cloudflare)

게임 파일(`../answer-dash`)과 실시간 방 서버를 Cloudflare Workers 한 곳에 올립니다.
올리고 나면 `https://answer-dash.<내-이름>.workers.dev` 같은 주소가 생기고,
학생은 로그인 없이 그 주소나 선생님 방 QR로 바로 들어옵니다.

## 처음 한 번만

1. [Cloudflare](https://dash.cloudflare.com/sign-up)에 무료로 가입합니다 (카드 필요 없음).
2. 이 폴더에서 터미널을 열고 준비물을 설치합니다.

   ```bash
   npm install
   ```

3. Cloudflare에 로그인합니다. 브라우저 창이 열리면 **Allow**를 누릅니다.

   ```bash
   npx wrangler login
   ```

## 올리기 (게임을 고칠 때마다 다시)

```bash
npm run deploy
```

처음 올릴 때 workers.dev 하위 주소(내 이름)를 정하라고 물으면 원하는 영어 이름을 넣습니다.
끝나면 화면 마지막 줄에 사이트 주소가 나옵니다.

## 내 컴퓨터에서 미리 해 보기

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:8787` 을 탭 두 개로 열면 서로 같은 방에 들어갈 수 있습니다.

## 무료 한도

- 하루 요청 10만 건 (한국 시간 오전 9시에 다시 채워짐).
- 학생 화면은 1초에 6번 위치를 보내고, 서버는 받은 메시지 20개를 요청 1건으로 셉니다.
  30명이 40분 동안 하면 약 2만 2천 건이라 하루 네 교시 정도 쓸 수 있습니다.
- 한도를 넘으면 그날은 같이 하기가 안 되고 혼자 연습만 됩니다.

## 알아 둘 점

- 로그인이 없으니 주소와 방 번호를 아는 사람은 누구나 들어올 수 있습니다. 이름도 각자 정합니다.
- `wrangler.jsonc`의 `ALLOWED_ORIGINS`를 비워 두면, 이 사이트에서 연 게임만 서버를 쓸 수 있습니다.
- 같은 게임 파일은 claude.ai 아트팩트에서 열면 claude.ai의 방 기능을, 이 사이트에서 열면 이 서버를 씁니다.
